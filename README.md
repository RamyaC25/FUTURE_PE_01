# FUTURE_PE_01

## Task 1 – AI Website Copy Generator for a Local Business

This project was completed as part of the Future Interns Prompt Engineering Internship.

### Business

**Glow Beauty Salon**  
Shivamogga, Karnataka

### Objective

The objective of this task is to use structured AI prompts to generate professional, simple and persuasive website copy for a local beauty salon.

### Tool Used

ChatGPT was used to design, refine and test the structured prompts and generate the website copy outputs for this project.

### Deliverables

- Homepage website copy
- Services page copy
- Call-to-Action (CTA) sections
- Structured prompts
- Prompt logic and AI workflow
- Key learnings

### Services Covered

- Haircut & Hair Styling
- Facial
- Bridal Makeup
- Manicure & Pedicure
- Hair Spa
